# 복붙용 효과 프롬프트 20개

클로드(또는 다른 AI 코딩 도구)에 그대로 붙여 넣는 지시문이다. `[대괄호]`는 사용자 상황으로 채운다.
비워 두면 AI가 임의로 정하니, 최소한 **적용 위치**와 **색**은 채우는 게 좋다.

모든 프롬프트 끝에 공통으로 붙는 조건(필요하면 그대로 덧붙인다):

> 외부 라이브러리 없이 [HTML/CSS/JS | React + Tailwind]로 만들어줘. `prefers-reduced-motion: reduce`면 움직임을 멈춘
> 정지 화면으로 보여주고, 모바일에서도 자연스럽게 보이게 해줘. 애니메이션은 transform/opacity 위주로, 화면 밖에선 멈추게.

### 01 Liquid Motion · 리퀴드 모션
[히어로 섹션] 배경에 액체처럼 서로 붙었다 떨어지는 블롭 애니메이션을 만들어줘. SVG gooey 필터(feGaussianBlur로
흐리게 한 뒤 feColorMatrix로 알파를 날카롭게)를 써서 원 4~6개가 천천히 떠다니며 합쳐졌다 갈라지게 하고, 그중 하나는
마우스를 부드럽게(lerp) 따라오게 해줘. 색은 [메인 컬러]에서 [보조 컬러]로 가는 그라데이션. 헤드라인은 블롭 위에
선명하게 읽히도록 대비를 확보해줘.

### 02 Holographic · 홀로그래픽
[멤버십 카드 / 상품 카드]에 홀로그램 포일 효과를 넣어줘. 무지갯빛 linear/conic 그라디언트 레이어를 mix-blend-mode
(color-dodge 또는 overlay)로 겹치고, 마우스 위치를 CSS 변수로 받아 그라디언트 각도·위치와 카드의 3D 기울기
(perspective + rotateX/Y)가 함께 바뀌게 해줘. 반짝이는 하이라이트(glare)가 커서를 따라 움직이고, 터치 기기에선
마우스 대신 천천히 자동으로 일렁이게. 카드 내용: [카드에 들어갈 텍스트/로고].

### 03 Claymorphism · 클레이모피즘
[버튼 / 카드 / 토글] 컴포넌트를 클레이모피즘 스타일로 만들어줘. 큰 border-radius, 파스텔 [색상 팔레트], 바깥 그림자
하나 + 안쪽 그림자 두 개(왼쪽 위 밝게, 오른쪽 아래 어둡게)로 찰흙처럼 볼록한 입체감. 누르면 살짝 찌그러지듯 작아지고
그림자가 얕아졌다가 탄성 있게(cubic-bezier 스프링) 돌아오게. 카드는 아주 천천히 둥실 떠 있는 애니메이션.

### 04 Halftone · 하프톤
[히어로 / 섹션 배경]에 만화 인쇄 같은 하프톤 효과를 만들어줘. 캔버스에 [원본 도형/이미지: 예) 회전하는 도넛]을
오프스크린으로 그리고, 격자(45도 회전)마다 밝기를 샘플링해서 어두울수록 큰 점을 찍어줘. 색은 [점 색상]과 [배경 색상]
두 가지로. 도형이 천천히 회전/맥동하면서 점 크기가 실시간으로 변하게. devicePixelRatio는 2로 제한하고 화면 밖에선 정지.

### 05 Isometric · 아이소메트릭
[기능 소개 섹션]에 아이소메트릭 3D 장면을 만들어줘. CSS 3D(rotateX 60deg + rotateZ -45deg, preserve-3d)로
[블록 / 레이어 카드 N개]를 쌓고 면마다 명암을 다르게 칠해줘. 마우스를 올리면 해당 레이어가 translateZ로 떠오르며
그림자가 길어지고, 평소엔 아주 살짝 위아래로 숨 쉬듯 움직이게. 각 레이어에 라벨: [레이어 이름들].

### 06 Kinetic Typography · 키네틱 타이포그래피
헤드라인 "[문구]"에 키네틱 타이포그래피를 적용해줘. 글자를 한 글자씩 span으로 쪼개(부모엔 aria-label로 원문, 글자 span은
aria-hidden) 인덱스별 지연을 줘서 아래에서 회전하며 튀어 오르듯 등장시키고, 등장 후엔 은은한 파도처럼 계속 출렁이게.
마우스 근처 글자는 살짝 커지거나 기울어지게 반응. "다시 재생" 버튼도 넣어줘.

### 07 Y2K Chrome · Y2K 크롬
"[타이틀 문구]"를 Y2K 크롬(리퀴드 메탈) 글씨로 만들어줘. background-clip:text에 은색·하늘색 다단 그라디언트(위는 하늘
반사, 가운데 어두운 수평선, 아래는 밝게)를 쓰고 얇은 외곽선과 글로우를 더해줘. 빛이 글자 위를 주기적으로 쓸고
지나가는 하이라이트 애니메이션, 주변에 반짝이는 4각 별(sparkle)들. 배경은 [짙은 남색 / 파스텔]. 같은 스타일의 크롬
알약 버튼도.

### 08 Paper Cutout · 페이퍼 컷아웃
[히어로 섹션]을 종이를 오려 겹친 듯한 페이퍼 컷아웃 장면으로 만들어줘. [언덕 / 파도 / 구름 / 해] 모양 레이어 4~6장을
겹치고 레이어 사이에 부드러운 drop-shadow, 은은한 종이 질감(SVG feTurbulence 노이즈, 낮은 불투명도)을 넣어줘.
마우스를 움직이면 레이어마다 다른 깊이로 패럴랙스되고, 평소엔 살랑살랑 흔들리게. 색감은 [팔레트].
위에는 종이로 오린 카드에 헤드라인 "[문구]".

### 09 Infinite Zoom · 인피니트 줌
[인트로 / 로딩 화면]에 끝없이 빨려 들어가는 인피니트 줌 효과를 만들어줘. [사각형 / 원 / 둥근 사각형] 프레임 여러 개를
중첩해 지수적으로 커지게 하고, 화면을 넘어간 프레임은 다시 중앙에서 작게 등장하도록 순환시켜줘. 순환 순간에 툭 끊기지
않게 새 프레임은 페이드인, 오래된 건 페이드아웃. 색은 [번갈아 쓸 색 2~3개]. 가운데에 "[문구]" 헤드라인.

### 10 Vaporwave · 베이퍼웨이브
[히어로 섹션]을 베이퍼웨이브 스타일로 만들어줘. 가로 줄무늬로 잘린 석양 태양(repeating-linear-gradient 마스크),
원근감 있게 눕힌 네온 그리드 바닥(CSS 3D rotateX)이 화면 쪽으로 끝없이 흘러오게(background-position 애니메이션),
핑크·보라·시안 팔레트, 은은한 스캔라인. 헤드라인 "[문구]"는 자간 넓은 레트로 서체 느낌에 핑크/시안 text-shadow.

### 11 Text Scramble · 텍스트 스크램블
헤드라인에 텍스트 스크램블 효과를 넣어줘. 글자가 무작위 기호(!<>-_\/[]{}—=+*^?#)로 돌다가 왼쪽부터 차례로 목표 문구로
풀리게 하고, "[문구1]" → "[문구2]" → "[문구3]"을 순환하게. 재사용 가능한 TextScramble 클래스로 만들고, 내비/버튼 라벨은
hover·focus 때 같은 효과로 한 번 섞였다 풀리게. 글자 수가 바뀌어도 레이아웃이 흔들리지 않게 폭을 고정하고,
스크린리더에는 실제 문구만 읽히게(aria-label, aria-live="polite").

### 12 Bauhaus · 바우하우스
[포트폴리오 / 소개 섹션]을 바우하우스 스타일로 만들어줘. 빨강·파랑·노랑 + 검정, 미색 배경. 격자 타일마다 원, 반원,
4분원, 정사각형, 삼각형을 배치하고 차례로 회전·슬라이드하며 등장시킨 뒤 아주 느리게 기계적으로 회전. 타일에 마우스를
올리면 도형이 90도 돌거나 다른 도형으로 바뀌게. 굵고 촘촘한 대문자 헤드라인 "[문구]"를 격자 안에 배치.

### 13 Neubrutalism · 뉴브루탈리즘
[랜딩 페이지 / 컴포넌트 세트]를 뉴브루탈리즘 스타일로 만들어줘. 3px 검정 테두리, 블러 없는 딱딱한 오프셋 그림자
(6px 6px 0 #000), [노랑 / 핑크 / 라임 / 파랑] 원색 면, 두껍고 큰 글씨. 카드, 메인 버튼(누르면 그림자 방향으로
6px 이동하며 그림자 0), 태그 배지 줄, 입력창을 포함하고, 위에 흘러가는 마키 띠를 하나 넣어줘.

### 14 Shape Morph · 셰이프 모프
[히어로 오브젝트 / 아이콘]에 도형이 다른 도형으로 부드럽게 변하는 셰이프 모프를 만들어줘. [원 → 별 → 하트] 순서로
반복. SVG path는 같은 개수의 큐빅 베지어 명령으로 그려서 숫자를 보간(라이브러리 없이 JS로)하고, 간단한 버전으로
border-radius 8값 블롭 모프도 함께. 도형이 바뀔 때마다 아래 라벨 "[라벨들]"도 바뀌게. 채우기는 [그라디언트 색].

### 15 Memphis Design · 멤피스 디자인
[이벤트 / 프로모션 섹션]을 80년대 멤피스 디자인으로 꾸며줘. 크림색 배경 위에 구불구불한 선(SVG), 지그재그, 점 격자,
삼각형 색종이, 반원을 검은 외곽선과 [원색·파스텔 팔레트]로 흩뿌리고, 도형마다 다른 속도로 천천히 떠다니며 회전하게.
마우스에 살짝 패럴랙스. 가운데엔 딱딱한 그림자를 가진 카드에 헤드라인 "[문구]".

### 16 Line Animation · 라인 애니메이션
[아이콘 세트 / 일러스트 / 서명]이 선으로 스스로 그려지는 라인 애니메이션을 만들어줘. SVG path에 pathLength="1"을 주고
stroke-dasharray/stroke-dashoffset으로 순서대로(stagger) 그려지게. 스크롤해서 화면에 들어올 때 다시 그려지고
(IntersectionObserver), "다시 그리기" 버튼도. 카드에 마우스를 올리면 카드 테두리가 한 바퀴 그려지는 효과도 넣어줘.
선 색은 [색상].

### 17 Low Poly · 로우 폴리
[히어로 배경]을 캔버스 로우 폴리 메시로 만들어줘. 흔들린(jitter) 격자 점을 삼각형으로 나누고, 삼각형 중심 위치의
그라디언트 색([색1] → [색2])에 마우스를 따라다니는 가상 조명으로 명암을 줘서 면이 보이게. 꼭짓점이 sin 오프셋으로
천천히 움직여 면이 반짝이듯 변하게. 위의 헤드라인 "[문구]"는 반투명 유리 패널로 대비 확보.

### 18 Squash and Stretch · 스쿼시 앤 스트레치
애니메이션 원칙 스쿼시 앤 스트레치를 [버튼 / 아이콘 / 캐릭터]에 적용해줘. 공이 떨어질 땐 세로로 늘어나고(scaleY>1,
scaleX<1), 바닥에 닿으면 납작해지고(transform-origin bottom), 부피는 대략 유지되게. 그림자도 높이에 따라 커졌다
작아지게. 버튼은 누르면 젤리처럼 눌렸다가 스프링으로 출렁이며 돌아오게.

### 19 Grainy Gradient · 그레이니 그라디언트
[히어로 / 섹션 배경]에 그레이니 그라디언트를 만들어줘. 크게 흐린 원형 그라디언트 3~5개([팔레트: 예) 노을 오렌지·핑크·
보라])가 천천히 떠다니며 섞이는 메시 그라디언트 위에, 인라인 SVG feTurbulence로 만든 필름 그레인 노이즈를
mix-blend-mode overlay/soft-light로 덮어줘. 위에 헤드라인 "[문구]", 부제, 유리 질감 버튼.

### 20 Glitch · 글리치
"[타이틀 문구]"에 글리치 효과를 넣어줘. ::before/::after로 같은 글자(content: attr(data-text))를 빨강/시안으로 어긋나게
겹치고(mix-blend-mode screen), clip-path inset 조각이 steps() 키프레임으로 툭툭 튀게. 평소엔 잠잠하다가 가끔 짧게
터지는 방식으로, 깜빡임은 초당 3회 미만. 스캔라인 오버레이와 hover 시 글리치되는 버튼도. 스크린리더는 원문만 읽게.
