05

스크롤 진행 바Scroll progress

글을 얼마나 읽었는지. 아래 글을 스크롤해 보세요.

이름을 알면 대화가 빨라진다

“위에 차오르는 거 있잖아요”라고 말하면 듣는 사람마다 다른 걸 떠올립니다. 업로드 막대일 수도, 스토리 막대일 수도 있죠.

스크롤 진행 바는 읽기 페이지 맨 위에 고정된 얇은 선입니다. 독자가 글의 어디쯤 왔는지 알려 주고, 끝까지 읽을 동기를 줍니다.

스크롤 이벤트마다 width를 바꾸면 레이아웃 계산이 반복됩니다. transform: scaleX()로 바꾸면 합성 단계에서만 처리돼 부드럽습니다.

최신 브라우저에서는 animation-timeline: scroll()로 자바스크립트 없이도 만들 수 있습니다. 지원하지 않는 브라우저를 위해 짧은 폴백을 함께 둡니다.

스크롤바가 이미 같은 정보를 주기 때문에, 스크린리더에는 숨겨 두는 장식 요소로 처리합니다.

여기까지 읽으셨다면 막대가 끝까지 찼을 거예요.
